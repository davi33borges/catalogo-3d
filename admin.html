Configurar admin

Isto é feito só uma vez. O token do GitHub fica guardado criptografado com a sua senha; depois, o login pede apenas a senha.

  1. Abra github.com/settings/personal-access-tokens/new
  2. Repository access: Only select repositories → catalogo-3d
  3. Permissions → Repository → Contents: Read and write
  4. Gere o token e cole abaixo

Admin 3D

Digite sua senha para editar o catálogo.

Esqueceu a senha ou o token expirou? Configurar de novo
